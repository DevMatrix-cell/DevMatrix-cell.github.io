# Dasari Manojkumar — Personal Portfolio

A responsive, dependency-free personal portfolio for Dasari Manojkumar, built with semantic HTML, editorial CSS, and vanilla JavaScript. The current visual direction is **The Manojkumar Archive**: aged ivory, forest green, walnut, antique brass, and heritage typography.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Notes

- Project links point to the public `DevMatrix-cell` GitHub repositories.
- The contact address is intentionally marked as a placeholder until a confirmed inbox is configured.
- Theme preference is stored locally in the browser.
- No build step or dependency installation is required.
- Project case studies are based on verified public repository evidence. The portfolio does not invent screenshots or unavailable social links.
- Project cards open dedicated, shareable case-study pages at `project.html?project=<slug>`.
- The contact form saves a local draft and clearly states that no message was sent until a real delivery endpoint is configured.
